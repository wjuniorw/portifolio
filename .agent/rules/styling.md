# Rule: Styling with Vanilla Extract

## Context & Goal
The project uses **Vanilla Extract** (`@vanilla-extract/css`) as the official styling engine. Styles are written in TypeScript (`*.css.ts`), verified at compile time, and extracted to static CSS with zero runtime overhead.

---

## MUST

1. **Use of `style` and `styleVariants`**:
   - Base styles must use the `style({})` function.
   - Visual modifiers and variants (e.g., colors, sizes, types) must use `styleVariants({})`.
2. **Exclusive Consumption of `vars`**:
   - Every value for color, font, spacing, or radius must be read from `vars` imported from `@core/ds/tokens.css`.
3. **Media Queries Inside the Style Object**:
   - Responsive rules must be declared inside the `'@media'` property of the Vanilla Extract style itself.
   - Default breakpoint for 3-column to 1-column grids: `'(max-width: 860px)'`.
4. **Pseudo-classes and Interactive States**:
   - Use `:hover`, `:active`, `:focus-visible` directly or via `selectors: { ... }`.
   - Always provide a clear `:focus-visible` visual style for accessibility.
5. **Smooth Transitions**:
   - Color and motion transitions should use durations between `0.15s` and `0.3s` with an `ease` curve.

---

## MUST NOT

1. **DO NOT use CSS-in-JS libraries with runtime**: It is forbidden to install or use libraries like Styled Components or Emotion that inject `<style>` at runtime.
2. **DO NOT use inline styles in JSX (`style={{ ... }}`)**: CSS must be pre-compiled by Vanilla Extract.
3. **DO NOT create unnecessary global selectors**: The use of `globalStyle` is reserved for fundamental resets and theme variable bridges. Components must use locally scoped classes generated by Vanilla Extract.

---

## Anti-pattern → Correct

### 1. Responsive Declaration

❌ **Anti-pattern**: Defining media queries with loose manual CSS or unconfigured Tailwind classes.
```tsx
<div className="grid md:grid-cols-3 grid-cols-1">...</div>
```

✅ **Correct**: Typed media query inside the `.css.ts` file.
```ts
// Component.css.ts
import { style } from '@vanilla-extract/css'

export const grid = style({
  display: 'grid',
  gap: '24px',
  gridTemplateColumns: 'repeat(3, 1fr)',
  '@media': {
    '(max-width: 860px)': {
      gridTemplateColumns: '1fr',
    },
  },
})
```

### 2. Creating Variants

❌ **Anti-pattern**: Manual string concatenation and complex conditional styles in JSX.
```tsx
<div className={type === 'primary' ? styles.primaryCard : styles.secondaryCard} />
```

✅ **Correct**: Use of `styleVariants`.
```ts
// Component.css.ts
import { style, styleVariants } from '@vanilla-extract/css'
import { vars } from '@core/ds/tokens.css'

export const baseCard = style({
  padding: vars.spacing.lg,
  borderRadius: vars.borderRadius.xl,
})

export const cardVariants = styleVariants({
  standard: {
    backgroundColor: vars.colors.surface,
    border: `1px solid ${vars.colors.stroke}`,
  },
  highlighted: {
    backgroundColor: vars.colors.primaryTint,
    borderColor: vars.colors.primary500,
  },
})
```
